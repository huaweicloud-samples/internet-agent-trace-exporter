# 架构说明 —— 智能体链路导出器（agent-trace-exporter）

> 华为云实践文档。本方案将智能体运行时 / 框架写入日志的 trace span，实时抽取、按属性过滤、转 OTLP 格式，并扇出到任意 OTLP 兼容后端，命中记录归档对象存储 30 天。

---

## 2. 组件清单

| 组件 | 华为云服务 | 职责 |
|---|---|---|
| 日志入口 | 云日志服务 LTS（`agent-traces`/`spans`） | 智能体运行时写入 JSON span |
| 触发器 | FunctionGraph LTS 触发器 | 日志流新事件实时投递到函数（等价订阅过滤器） |
| 处理函数 | FunctionGraph（Python 3.10，内联代码） | 解码 → 过滤 → OTLP 转换 → 扇出 |
| 归档 | LTS 转储任务（周期 OBS） | 周期归档日志到对象存储（2min 可配） |
| 备份桶 | 对象存储服务 OBS | traces/ 前缀，AES256 加密、私有、30 天过期 |
| 权限 | IAM 委托（functiongraph） | 函数读 LTS + 写 OBS |

## 3. 关键设计点

1. **实时 + 归档双路径解耦**：实时导出走 LTS 触发器（秒级），归档走 LTS 转储任务（周期 2min），互不阻塞。
2. **默认零依赖**：处理函数以标准库实现 OTLP JSON 编码，`func_code` 内联交付，无需依赖包构建/上传。
3. **可切换 protobuf**：`otlp_encoding="protobuf"` 时挂 opentelemetry-proto 依赖包（`src/tools/build-dependency.sh`）。
4. **安全默认**：`dry_run="true"` 时函数仅记录不发送，确认端点可达后再切 false。
5. **过滤可配置**：`filter_span_attributes` 支持 `key=v1|v2`（多值）与尾缀 `*`（前缀匹配），默认 `*` 全放行。
6. **多端点扇出**：`otlp_endpoints` JSON 数组支持同时投递多个 OTLP 后端。
7. **三态处置协议**：`Ok / Dropped / ProcessingFailed` 保留在函数日志与返回摘要中，便于排障。

## 4. 数据流说明

- **写入**：智能体框架通过日志 SDK / 直接写入 LTS 日志流，每行一条 JSON span（或 OTLP 批次）。
- **触发**：LTS 触发器将新日志事件打包投递给函数（含 base64+gzip 信封）。
- **处理**：函数解码信封 → 提取 span → 按属性过滤 → 归一化为 OTLP JSON → 序列化 → HTTP 扇出。
- **归档**：LTS 转储任务周期将原始日志归档至 OBS `traces/` 前缀，30 天后过期删除。
- **失败处理**：导出失败（端点不可达/无端点配置）计数入返回摘要 `failed`，由函数日志留痕，可通过配置告警渠道观测（本仓库不强制绑定告警通道）。
